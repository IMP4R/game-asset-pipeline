# Autonomous refinement protocol (game-agnostic)
Continue your own run, preserving every previous report and attempt. Read original screenshots and failed critic reports yourself. No parent-supplied geometry or object inventory. You own analysis, reference selection, generation prompts, processing and assembly.

1. Reopen originals BEFORE existing measurements. Independently re-evaluate floor separators versus wall/lip contours. Save explicit separate geometry items for floor/anchors and visible raised contours, fresh alternative hypotheses and genuinely held-out observations. Do not fit lattice from outer bottom silhouette. Register generated background's visible wall/negative-space contours separately from floor if necessary; no source pixels pasted. Compare originals/candidate in central and distant unobscured regions. Re-run geometry critic with current CRITIC.md before any new image submission.
2. Read all failed per-asset evidence, distinguish shape/camera errors from extraction/scale/material errors. Use local fixes ONLY when they preserve generated form and correspond to observed evidence. Do not anisotropically squash an entire sprite to conceal wrong geometry. Prefer targeted single-variant or small same-pose corrections, NOT a large atlas including unrelated failed objects. Image API reference contract remains two images per object: contextual crop + masked crop. Improve masked references yourself if contaminated by other objects; visible source crop is not full geometry. Prompts restore observed visible shape and consistently complete hidden regions, no redesign. Use additional image budget selectively on failures with largest screen-space impact.
3. Critics must review full objects at both enlarged scale and target screenshot scale, with observed-only source visibility and inferred completion distinguished. Split review manifests into coherent small groups if input count/latency is excessive; cover all variants in a final assets review before accepted output. Do not cherry-pick a good item to call the whole atlas pass. Corrected generated environment must be checked with registered visible wall contours.
4. Assemble and invoke independent scene critic. Fix local composition errors yourself, re-review updated bytes. Record what improved or worsened against previous A/B; never claim accepted because no budget remains. Reports may stay revise/uncertain but outstanding major errors must be named. Preserve immutable attempt files; keep report inputs stable during review.

Operational budgets are env configured. Existing submissions still count toward total IMAGE_REQUEST_LIMIT; never reset ledger. Review counts remain cumulative, CRITIC_MAX_REVIEWS is a per-stage TOTAL, not new allowance. No historical coordinates or hand-authored parent game scripts. Use existing session continuation. Final outputs include reconstruction, original-left final_ab, honest report, exact ledger and latest critic gates. Show what is actually achieved, not just analysis.
