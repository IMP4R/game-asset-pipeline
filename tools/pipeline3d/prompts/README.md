# Промпты пайплайна 3D-ассетов (tools/pipeline3d/prompts)

## Текущий конвейер — v4 (после мета-разбора 2026-09-25)

Скелет: **наблюдения → владение пикселями → корпус по экранным отношениям → проверяемый контракт → сборка по шлюзам → приёмка с правом инвалидировать контракт.** Конвейер работает для неизвестных игр без участия человека-артиста; все решения выводятся из кадров.

| Файл | Этап | Ключевая идея |
|---|---|---|
| `guru_asset_prompt_v4_observations.md` | Запрос 0 | Реестр ТОЛЬКО наблюдений. Запрещены z/r, материалы, «как бы вы сделали с нуля». Апскейл ≠ наблюдение. |
| `guru_asset_prompt_v4_pixels_body.md` | Запрос 1 | Проверка ВЛАДЕНИЯ пикселями (не функциональная проверка) + экранные отношения корпуса в обеих позах + матрица модельных гипотез. |
| `guru_fusion_template_v4.md` | Запрос 2 (слияние) | Статусы OBSERVED/HYPOTHESIS/PRODUCTION_CHOICE/UNRESOLVED; канонические экранные ограничения; профиль фальсифицируем (PROFILE_INVALID); внешний тёмный слой по умолчанию НЕ часть ассета; rigid-поворот — гипотеза; «толстая кромка» без метрики запрещена. |
| `guru_builder_template_v4.md` | Сборка | Шлюзы A/B/C: flat-маски и допуски раньше beauty; статус остановки PASS / FAIL_PROFILE / FAIL_MODEL_CLASS вместо «числа итераций»; внешний слой не строится при UNRESOLVED. |
| `guru_verify_template_v4.md` | Приёмка | Сверяет РЕФЕРЕНС против РЕЗУЛЬТАТА, не контракт против результата; контракт может быть инвалидирован; вердикты CONFIRMED/MISMATCH/INSUFFICIENT_EVIDENCE/WRONG_MODEL_CLASS. |

## Правила, действующие во всех шаблонах v4

1. Масштабная нормализация обязательна: рендер и референс сравниваются только при равной ширине корпуса; лист приёмки — только пары реф|финал.
2. Наблюдение / гипотеза / производственное решение — разные статусы; гипотеза не может быть критерием приёмки.
3. Один объект — одна логика, применяемая к ЛЮБОМУ ассету (никаких частных «ручек ведра» в общих правилах).
4. Итерации не измеряются числом; готовность — допусками и статусом.
5. Экранная проекция — продукт; screen-space решения (outline, presentation mesh) легитимны для игровых ассетов.
