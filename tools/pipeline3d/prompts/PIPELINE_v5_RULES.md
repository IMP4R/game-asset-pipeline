# ПАЙПЛАЙН v5 — ПРАВИЛА ДЛЯ ВСЕХ ЗАПРОСОВ (общие, действуют всегда)
# Принято по итогам полного провала прогона v4 (2026-09-25) и консультации у автора контрактов.
# ГЛАВНОЕ ПРАВИЛО: сначала восстанавливается НАБЛЮДАЕМОЕ ИЗОБРАЖЕНИЕ объекта в его игровых
# условиях, и только потом выбирается 3D-модель, способная это изображение воспроизвести.
# Класс модели заранее не предполагается. Экранные координаты НЕ переводятся в z профиля.
# Бюджет: максимум 10 запросов на ассет. Рендеры с материалом обязательны в каждом этапе.

## 1. Что смертно (запрещено во всех шаблонах)
- Считать внешний silhouette IoU, общий foreground IoU, XOR маски, совпадение bbox доказательством сходства. Это только диагностика.
- FIDELITY (меш равен своей декларации) — не сходство с референсом.
- Называть неоднозначную область established-фактом («ручка», «обод», «дно», «тень») до проверки владения.
- Переводить ширины на экранных строках (screen_y_0.2 и т.п.) в уровни 3D-профиля.
- Принимать осесимметричное тело как данность.
- Выпускать результат без рендеров.
- Улучшать одно состояние ценой превращения второго в другое.

## 2. Обязательный пакет рендеров после каждой правки сборщика
A. **Beauty** — тот же ракурс/ориентация/масштаб, реальный материал, мягкий игровой свет, нейтральный фон, БЕЗ служебных цветов и сетки. Минимум 1024 px по длинной стороне.
B. **Flat color** — объект одним цветом, контрастный фон, без освещения (для сравнения силуэта и вложенных границ).
C. **Contour overlay** — внешний контур результата на референсе + внутренний контур ОТДЕЛЬНО (не сливать в одну маску), плюс contour XOR.
D. **Material diagnostic** — base color, roughness, cavity/AO.
E. Второе состояние (inverted) — те же A–D, начиная с запроса 7.
Плюс обязательный crop объекта шириной 500–700 px для оценки полости и гладкости.
Скрипт, который считает только маску, НЕ считается выполнением этапа.

## 3. Что обязан видеть и говорить сборщик после каждого рендера
1) что уже узнаваемо; 2) какой ОДИН дефект сильнее всего разрушает идентичность; 3) его природа (геометрия / материал / свет / камера / ownership); 4) какая конкретно правка следующая; 5) не достигнут ли предел наблюдаемости.
Если рендер выглядит как другой объект — это важнее любого улучшения IoU.

## 4. Обязательные содержательные проверки (не площадь, а структура)
- Внешний контур: среднее расстояние, Hausdorff95, max локальное отклонение, положение максимальной ширины.
- Внутренняя область ОТДЕЛЬНО: cavity IoU, площадь, центр, форма границы, contour distance, отношение cavity/outer width, читаемость полости.
- Обод/граница отверстия в нескольких местах (перед, лево, право): толщина и симметрия.
- Ключевая форма второго состояния: купол, плечо, переход, нижняя часть, тёмная полоса.
- ГЛАДКОСТЬ: кривизна профиля, число видимых переломов, скачки нормалей, отсутствие концентрических террас; видимый профиль должен быть C1 (лучше C2). Профиль из малого числа линейных отрезков без сглаживания не принимается.
- МАТЕРИАЛ: hue/value/saturation, roughness, контраст внутренней области относительно внешней, наличие блика, читаемость полости — при том же свете, что в игре, а не в «красивом» сетапе.
- Согласованность состояний: кандидат проходит оба состояния одновременно.

## 5. Правило остановки
Крутить бессмысленно, если одновременно: внешний силуэт стабилен после двух кругов; cavity/rim/купол совпадают по форме, а не по площади; beauty узнаваем в исходной композиции; материал не маскирует геометрию; состояния не противоречат; последние две правки не уменьшили главный дефект.
Остановка определяется ОТСУТСТВИЕМ perceptual improvement, а не достижением числового порога.
Если узнаваемость не достигнута за 10 запросов — отдаётся честный диагностический пакет со статусом `UNRESOLVED_REFERENCE_MATCH` (не RELEASE, не FIDELITY_PASS).
